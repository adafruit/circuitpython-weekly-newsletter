# 参与贡献！

最简单的贡献方式是将您的个人信息及相关资料通过邮件发送至 cpnews(at)adafruit(dot)com。

对于愿意操作的用户，也欢迎通过 GitHub 进行贡献。请直接在 GitHub 的 `_drafts` 目录中修改最新草稿，而无需进行分叉/克隆/创建分支/编辑/提交 PR 操作。每份草稿的文件名均为 yyyy-mm-dd-draft.md，采用 [Markdown](https://www.markdownguide.org/) 格式。编辑完成后系统会询问是否要创建 Pull Request（PR），请执行该操作并添加说明文字。

邮件会在每周五下午被安排发送。

如果觉得直接编辑有些麻烦，也可以在 Issues 中发帖，不过还是建议优先通过邮件发送。

## 在您的 Pull Request 中添加图片与动画 GIF（资源）

请在提交问题时使用的所有资源文件名前加上格式为“yyyymmdd”加唯一字符串的日期前缀，例如 20230704neopixel.jpg。

为控制文件大小，建议使用JPG格式。
* 所有图片的宽度**必须≤550像素**
* 请避免使用带黑边的裁剪版图片。

动画GIF：

所有视频必须为动画GIF格式，且不能包含声音。较长的视频可以放在网站上并通过链接呈现，而非直接嵌入。

* 如有必要，可通过 https://twittervideodownloader.com/ 进行下载  
* 使用 https://ezgif.com/ 转换为 GIF 格式，宽度需控制在 550 像素以内，且**文件大小必须小于 1MB**

为减小GIF文件大小，可将其缩小或进行优化处理。也可以将宽度裁剪至400像素以内，并建议时长控制在5秒左右。
