# 参加してください！

貢献する最も簡単な方法は、ご自身の情報や関連するファイルを cpnews(at)adafruit(dot)com にメールで送信することです。

GitHubを使った貢献も歓迎します。fork/clone/branch/edit/PRを行うのではなく、直接GitHub上の `_drafts` ディレクトリ内の最新ドラフトを編集してください。各ドラフトは[Markdown](https://www.markdownguide.org/)形式で、ファイル名がyyyy-mm-dd-draft.mdとなっています。編集が終わるとPull Request（PR）を作成するかどうか尋ねられますので、そうして説明文も追加してください。

投稿は金曜日の午後に順番待ちとなります。

編集が面倒な場合はIssuesに投稿しても構いませんが、できればメールでの送付を強く推奨します。

## プルリクエストに画像やアニメーションGIF（アセット）を追加する方法

Issue内のすべてのアセットファイル名の先頭に、yyyymmddという形式の日付と一意な文字列を付けてください。例：20230704neopixel.jpg

サイズの都合上、JPGファイルを使用することを検討してください。
* すべての画像は**幅が550px以下でなければなりません**
* 黒いバーがあるようなレターボックス形式の画像は避けてください。

アニメーションGIF：

すべての動画はアニメーションGIF形式のみでなければなりません。音声は含まれません。長尺の動画については、ウェブサイト上に掲載しリンクを貼る形式とし、埋め込みは行いません。

* 必要な場合はhttps://twittervideodownloader.com/を使って動画を保存する  
* https://ezgif.com/を使ってGIFに変換し、幅は550px以下にし、**ファイルサイズは必ず1MB未満でなければならない**

GIFのファイルサイズを小さくするには、画像自体を縮小したり最適化したりしてください。また、幅を400px未満にトリミングしたり、長さは最大5秒に抑えることも検討してください。
