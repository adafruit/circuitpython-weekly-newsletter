## Microbe: A New Lightweight IDE for MicroPython

[![Microbe](../assets/20261019/20261019microbe.jpg)](https://github.com/mikayelgr/microbe)

Microbe is a new lightweight IDE for MicroPython by Mikayel Grigoryan. It talks directly to a board, giving a Python language server that knows the machine and network, and flashes firmware directly. It is built on Tauri instead of Electron, using an operating system's webview, and it has a Rust core - [GitHub](https://github.com/mikayelgr/microbe).

## Casio-MicroPython Released

[![Casio-MicroPython](../assets/20261019/20261019calc.jpg)](https://github.com/Joe-Heffer/Casio-MicroPython)

Casio-MicroPython allows one to write MicroPython programs for the Casio fx-CG100 graphing calculator, with tools to check and run them on a laptop. Programs are a single .py file of no more than 300 lines, the limit for one file in the calculator’s Python app. Graphics use Casio’s casioplot module. The `turtle` and `matplotlib.pyplot` modules are also available on the calculator. MIT License - [GitHub](https://github.com/Joe-Heffer/Casio-MicroPython).

## Python 3.15 Goes Global With UTF-8 Support & More

[![Python 3.15 goes global with UTF-8 support](../assets/20261019/20261012p15.jpg)](https://www.theregister.com/devops/2026/10/14/python-315-goes-global-with-utf-8-support/5302966)

After a week’s delay, the new version of Python, v3.15, was released. With it comes a proper profiler, an experimental just-in-time compiler, and a tightening of dictionary structures.  It also offers a time-saving Lazy Import option for programs to not load modules until needed, the implementation of which ironically halted this release until a few last-minute regressions were sorted.

"But of all these new delicacies spread before the Pythonistas, the data wranglers of the bunch may most appreciate default UTF-8 support across all platforms. And when we say “all platforms,” we’re really just throwing shade at Windows (as usual). Python has defaulted to macOS and Linux Python environments for some time now." - [The Register](https://www.theregister.com/devops/2026/10/14/python-315-goes-global-with-utf-8-support/5302966).

Python 3.15 delivers a native-by-default experience on Windows on Arm - [Windows Developer Blog](https://blogs.windows.com/windowsdeveloper/2026/10/14/python-3-15-delivers-native-by-default-experience-on-windows-arm/).

Python 3.16.0 alpha 1 is now available - [Python Insider](https://blog.python.org/2026/10/python-3160-alpha-1-is-now-available/).

## The Pirate Language Version of CircuitPython Has Been Dropped

Paulk Cutler notes on Mastodon that the Pirate language version of CircuitPython was removed in the latest GitHub pull request. ## What’s the CircuitPython team up to this week?

What is the team up to this week? Let’s check in:

**Dan**

I'm continuing to add features to the Zephyr port. I added `bitbangio` and am now finishing changes to make the board buses be allocated dynamically instead of statically, to match how CircuitPython has done it before. I've also fixed several BLE bugs and improved BLE error reporting.

**Tim**

[![Tim](../assets/20261019/20261019tim.jpg)](https://www.circuitpython.org/)

This week I discovered that there are SSTV images transmitted in HF bands by ham radio operators. I've adapted the ARISS SSTV event code to handle signals from both the ISS and the ones sent by terrestrial hams. I also made the combined version of the project code support either DVI display, or a small OLED automatically based on whichever is connected. The antennas required to receive on the HF bands used by hams are different from the ones needed to pickup frequencies used by the ISS. I built a long wire antenna, and an MLA-30 active loop antenna and have successfully captured SSTV photos on both. Here are a few of the neat photos that have been received and decoded on the Fruit Jam.

**Liz**

This week I published the [Fruit Jam Motion Tracking Eyeballs guide](https://learn.adafruit.com/fruit-jam-motion-tracking-eyeballs). This demo uses the new USB host webcam support to track motion. When motion is detected, a pair of monster eyes appear on the DVI display and their gaze points to the coordinates where the motion was detected in the camera's field of view. This project is made possible with two Turbo modules: one to handle drawing the monster eyes and one to compare each camera frame to detect motion and calculate where the eyes should gaze.

## Call for Help -- Translating CircuitPython is now easier than ever

[![CircuitPython translation statistics on weblate](../assets/20261019/20261019weblate.jpg)](https://hosted.weblate.org/engage/circuitpython/)

One important feature of CircuitPython is translated control and error messages. With the help of fellow open source project [Weblate](https://weblate.org/), we're making it even easier to add or improve translations.
