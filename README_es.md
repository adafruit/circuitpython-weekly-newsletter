# ¡Contribuya!

La forma más sencilla de contribuir es enviando un correo electrónico con su información y cualquier material relevante a cpnews(at)adafruit(dot)com.

También se aceptan contribuciones a través de GitHub por parte de quienes estén cómodos haciéndolo. Por favor, modifique el borrador más reciente directamente en la carpeta `_drafts` de GitHub, en lugar de hacer fork/clone/branch/edit/PR. Cada borrador tiene como nombre de archivo yyyy-mm-dd-draft.md en formato [Markdown](https://www.markdownguide.org/). Una vez que termine de editarlo, le preguntará si desea crear una Pull Request (PR); hágalo y añada una descripción.

El envío se programa para las tardes de viernes.

Si editar el contenido le resulta demasiado complicado, puede publicarlo en las secciones de problemas, aunque lo ideal y altamente recomendable es enviar un correo electrónico.

## Añadir imágenes y GIF animados (activos) en tu Pull Request

Por favor, anteponga a los nombres de todos los archivos de recursos en una issue la fecha en el formato yyyymmdd seguida de una cadena única, por ejemplo: 20230704neopixel.jpg.

Tenga en cuenta la conveniencia de utilizar archivos JPG en cuanto al tamaño.
* Todas las imágenes **deben tener un ancho de <= 550 px**.
* Por favor, evite las imágenes con marcos, es decir, aquellas con barras negras.

GIF animados:

Todos los videos deben estar en formato de GIF animado únicamente. No habrá sonido. Los videos más extensos pueden publicarse en un sitio web e incluirse mediante un enlace en lugar de ser incrustados.

* Si es necesario, capture la imagen mediante https://twittervideodownloader.com/.  
* Conviértala a GIF usando https://ezgif.com/, con un ancho máximo de 550 px; **el archivo DEBE tener un tamaño inferior a 1 MB**.

Para reducir el tamaño del archivo GIF, haz que sean más pequeños o óptimízalos. También puedes recortarlos para que tengan una anchura de menos de 400 px, y considera un límite máximo de cinco segundos de duración.
